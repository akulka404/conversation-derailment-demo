# Conversation Derailment Demo

Simple setup instructions to run `streamlit_app.py`.

## 1) Create and activate a virtual environment

```bash
python -m venv .venv
source .venv/bin/activate
```

On Windows (PowerShell):

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

## 2) Install requirements

```bash
pip install -r requirements.txt
```

## 3) Download model file

Download the trained model and place it in the project root as:

`mmconv_model_train.pth`

Model link (placeholder): `TODO_REPLACE_WITH_MODEL_DRIVE_LINK`

## 4) Run the app

```bash
streamlit run streamlit_app.py
```
